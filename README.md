# Pakistan-Standard-Time-Analog-Clock-Using-PyQt-Library
The program is built to display an analog clock which displays an analog clock for the timezone selected on menu page

Features include:
    1. Object Oriented Code
    2. Modularity
    3. Use of PyQt5 library methods
    4. Use of datetime library for  realtime time tracking

** How to run **

    1. Install PyQt Library first using "pip install PyQt5"
    2. Use command "git clone https://github.com/notunknownfr/Pakistan-Standard-Time-Analog-Clock-Using-PyQt-Library.git" in your cmd
    3. Run your program
